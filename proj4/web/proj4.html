Part 0: Camera Calibration and 3D Scanning

Part 0.1: Calibrating Your Camera

I captured 30-50 images of the calibration ArUco tags from different angles and distances. Using OpenCV's ArUco detector, I extracted corner coordinates and computed the camera intrinsics and distortion coefficients using cv2.calibrateCamera().

Part 0.2: Capturing a 3D Object Scan

I selected my favorite object and captured 30-50 images from different angles, ensuring consistent camera settings and zoom level as used during calibration. The images were captured at a uniform distance of about 10-20cm from the object.

Part 0.3: Estimating Camera Pose

Using the calibrated camera intrinsics, I estimated the camera pose for each image using cv2.solvePnP(). This solves the Perspective-n-Point (PnP) problem to find the camera's extrinsic parameters (rotation and translation) relative to the ArUco tag's coordinate system.

Part 0.4: Undistorting Images and Creating a Dataset

I undistorted all images using cv2.undistort() to remove lens distortion, ensuring compatibility with the pinhole camera model assumed by NeRF. The dataset was packaged into a .npz file with training, validation, and test splits, including camera-to-world transformation matrices and focal length.

Part 2: Fit a Neural Radiance Field from Multi-view Images

Implementation Overview

Part 2.1: Create Rays from Cameras

  • Implemented camera-to-world coordinate transformation
  • Implemented pixel-to-camera coordinate conversion
  • Implemented pixel-to-ray conversion with origin and normalized direction

Part 2.2: Sampling

  • Implemented random ray sampling from multi-view images
  • Implemented stratified sampling along rays with perturbation for training
  • Set near=2.0, far=6.0, and n_samples=64 for the Lego scene

Part 2.3: Dataloading

  • Created a dataloader that samples rays from multi-view images
  • Returns ray origins, ray directions, and pixel colors

Part 2.4: Neural Radiance Field

  • Created an MLP that takes 3D coordinates and view direction as input
  • Outputs density and view-dependent color
  • Used positional encoding for both coordinates (L=10) and view direction (L=4)
  • Added input injection through concatenation in the middle of the network

Part 2.5: Volume Rendering

  • Implemented the volume rendering equation to composite colors along rays
  • Computed transmittance and alpha values for each sample
  • Used discrete approximation of the integral
